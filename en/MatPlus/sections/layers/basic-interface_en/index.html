Interface Overview

Layers Section

When we create or open a project, this is the interface we will see.

It is divided into three sections.

MatPlus Materials

In this section, you will find the list of materials contained in the meshes.
Only existing materials in the mesh can be added. Extra materials cannot be created.

With the Add object button, you can add the materials from the selected meshes.

With the Remove button, you can delete the materials from the selected meshes.

At the top of the interface, there are two additional buttons:

Left button: Opens the MatPlus project.

Right button: Deletes the selected project.

Layers

In this section, we can find all the tools that allow us to create the material.

Settings

In this MatPlus panel, we can configure various advanced parameters for each material individually.

AO (Ambient Occlusion)

Allows adjusting the level of ambient occlusion applied to the material using the Factor control, which defines the intensity of the effect.

Bump

This section manages bump mapping on the surface:

  • Height Strength: controls the strength of the applied height.
  • Height Distance: defines the maximum displacement distance of the bump.
  • Normal Strength: adjusts the intensity of the generated normals.

Additional Channels

From the Channels Settings section, we can add or remove extra channels depending on the material’s needs.

Sections

On the left, we can find the buttons for the other sections.

Layers Settings

This part works together with the Layers section. Here we can find all values, options, and channels.

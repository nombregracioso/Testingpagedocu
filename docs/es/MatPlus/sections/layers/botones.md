# Botones básicos

### Matplus Workspace

Este boton sirve para ocultar todos los paneles de blender y centrarte solo en el viewport y en el addon MatPlus.

### Layers/Settings

Elige entre el administrador de capas o la configuración de materiales.

### 3D/2D

Divide el viewport en dos vistas. Una para el 2D y la otra para el 3D.

### Channel selector

Selecciona un material o un canal de forma individual para visualizarlo en el viewport.

### Update all layer effects

Este botón actualiza la información en todos los efectos de capa a la vez.
